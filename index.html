Learning Through Technical Challenges.

Catatan perjalanan belajar memahami GitHub, menghadapi kendala teknis, dan mengenal proses pengelolaan kode dalam pengembangan website.

21 November 2026 / Web Development / Learning Journal
01 — THE EXPERIENCE

Belajar GitHub Tidak Selalu Berjalan Mulus

Hari ini, Sabtu, 21 November 2026, saya bersama tim IT dan pembina ekstrakurikuler IT, Pak Zull, mencoba melakukan proses commit dan push dari Visual Studio Code ke GitHub. Namun, percobaan tersebut belum berhasil karena beberapa kendala yang kami temui selama proses berlangsung.

Terdapat dua kendala utama yang menjadi catatan pembelajaran hari ini. Kendala pertama berkaitan dengan kondisi komputer Laboratorium TKJ, sedangkan kendala kedua terjadi ketika mencoba melakukan pendaftaran akun GitHub.

02 — TECHNICAL CHALLENGES

Kendala yang Ditemukan

ISSUE 01 / LABORATORY

Aplikasi Hilang Setelah Komputer Restart

Pada komputer Laboratorium TKJ, aplikasi desktop yang diinstal, seperti Adobe Premiere dan aplikasi lainnya, berhasil terpasang bahkan dapat digunakan seperti biasa. Namun, setelah komputer direstart, aplikasi yang sebelumnya diinstal tersebut kembali hilang.

Kondisi ini menjadi kendala karena aplikasi yang dibutuhkan untuk kegiatan praktik tidak dapat dipertahankan setelah komputer dinyalakan ulang.

ISSUE 02 / GITHUB ACCOUNT

Kendala Saat Mendaftar Akun GitHub

Kendala lainnya muncul pada tahap awal pendaftaran akun GitHub. Beberapa percobaan pendaftaran mengalami kegagalan ketika dilakukan berulang kali menggunakan IP yang sama.

Saat mencoba mendaftar, saya melakukan klik tombol berulang kali dengan jeda sekitar tiga detik. Proses tersebut tidak berjalan sesuai harapan sehingga pendaftaran akun menjadi salah satu kendala yang perlu diperhatikan.

03 — PERSONAL REFLECTION

Catatan Pembelajaran Hari Ini

Pengalaman hari ini memberikan saya pemahaman bahwa proses belajar teknologi tidak selalu berjalan sesuai rencana. Ada kendala yang muncul bahkan sebelum proses utama berhasil dilakukan.

Meskipun percobaan commit dan push dari Visual Studio Code ke GitHub belum berhasil, saya mendapatkan pengalaman mengenai beberapa hal teknis yang perlu dipahami, mulai dari kondisi komputer laboratorium hingga proses pembuatan akun GitHub.

Saya ingin menjadikan pengalaman ini sebagai bagian dari dokumentasi belajar, sehingga setiap kendala, percobaan, dan perkembangan project dapat tercatat dengan baik di repository GitHub.
